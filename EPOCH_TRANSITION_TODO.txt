Commit: 1c781f8

[RESOLVED] Partition Count Mismatch (250 vs 252)
------------------------------------------------
Root Cause: credits_observed not refreshed from AccountsDB
Fix: RefreshStakeCacheCreditsObserved reads from boundary slot
Confidence: HIGH - verified partition count matches

[RESOLVED] Vote Cache Missing Accounts
--------------------------------------
Root Cause: Strict failure on missing vote accounts
Fix: Changed from FATAL to warning; missing = ineligible stake
Confidence: HIGH - 88 failures are expected closed accounts

[RESOLVED] Partition Blockhash Bug
----------------------------------
Root Cause: Using LastBlockhash (grandparent) instead of Blockhash (parent)
Fix: Use prevSlotCtx.Blockhash for partition hashing
Confidence: HIGH - matches Agave/FD behavior

[RESOLVED] Stake Cache Full Scan on Resume
------------------------------------------
Root Cause: Cache not persisted frequently enough for crash recovery
Fix: Append-only pubkey index, flush after each block commit
Commit: 1cf0e26
Confidence: HIGH - reduces 30+ minute scan to ~minutes

[RESOLVED] Mid-Block Crash Stake Cache Corruption
-------------------------------------------------
Root Cause: Saving cache mid-block would include uncommitted updates
Fix: blockReplayInProgress flag, skip save if mid-block
Commit: 988c235
Confidence: HIGH

[RESOLVED] Diagnostic Panic Crashing Process
---------------------------------------------
Root Cause: Panic in background goroutine for bankhash fetch
Fix: Return error instead of panic
Commit: 5f13ceb
Confidence: HIGH
